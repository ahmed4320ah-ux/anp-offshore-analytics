# Sample data

- `Agg_Annual_KPI.csv` contains annual production summary measures.
- `Dim_Basin.csv` contains basin keys and labels for the dimensional model.

See the [data dictionary](../../docs/Final_Data_Dictionary_v3.csv) for definitions and the [V11.1 pipeline archive](https://github.com/ahmed4320ah-ux/anp-offshore-analytics/releases/download/v11.2.0/ANP_Offshore_Pipeline_V11_1.zip) for related code and validation notes.
